# Portfolio Site

Welcome to the repository for my personal portfolio site! This project was built from scratch to showcase my technical background, low-level and full-stack projects, research experience, and professional career. It's customizable, mobile responsive, and minimalistic. 

[Live Demo](https://portfolio-site-5rjo.onrender.com/)

## Features 
- **Customizable:** Edit the `portfolioData.json` and replace it with your own information. 
- **About Section:** Section to introduce yourself, who you are, what you do, and give people any extra information. This is mark down rendered, so you can bold text, italic, add links, etc.
- **Work Experience:** A section to show off your work experience as cards. The cards display your organization's name, your title, dates worked, a description, and also an additional link to your company if you want.
- **Projects:** A section to show off featured projects that you're proud of. Again this is rendered as sleek cards with hover effects. You get a project title, description, tags (e.g., "art", "programming", "leadership"), and a link to your project if needed. Also there's an additional project page for any non-featured projects, so extra stuff that's not as good but still there to show experience.
- **Social Links:** The side panel lets you show off your linkedin and github profiles. Your main page, in the experiences section, you have a link to your resume.

## Getting Started
1. First install Node.js. Docker and `Make` are optional. 
2. Clone the repo
3. Run `npm install && npm run dev`
4. Modify the `portfolioData.json` however you want.
